Model Architecture

This analytics dashboard visualizes the outputs of a highly optimized discrete-time stochastic SIR model built in Python. The simulation does not rely on continuous differential equations (ODEs), but rather tracks exact integer populations through probabilistic state transitions at each timestep.

  • S (Susceptible): Individuals capable of contracting the virus.
  • I (Infected): Individuals currently shedding the virus.
  • R (Removed): Individuals recovered or deceased (immune).
