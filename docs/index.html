Stochastic Epidemic Simulation

A discrete-time Markov chain approach to the SIR model on a finite population. Explore the stochastic behavior, extinction times, and sensitivity analysis.

The Model

The SIR (Susceptible-Infectious-Removed) model is implemented as an absorbing discrete-time Markov chain. The state of the system is tracked as the number of susceptible and infectious individuals.

100 Population Size (N)

Key Parameters

  • β (Beta): Infection rate 0.3 (Default)
  • γ (Gamma): Recovery rate 0.1 (Default)
  • Initial State I=1, S=99
